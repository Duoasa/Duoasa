# 你好，我是 Duoasa

**AI 原生产品设计师 · 以设计驱动产品构建**

拥有计算机专业背景和五年多 UI/UX 与产品设计经验。我结合设计、产品思维与 AI，将想法变成可以实际使用的产品，关注人与 Agent 的交互，以及桌面工具的体验。

[个人网站与产品](https://duoasa.com/)

## 项目介绍

| 项目 | 简介 |
| --- | --- |
| [QuotaView](https://github.com/Duoasa/QuotaView) | 面向 AI Agent 的 macOS 灵动岛，并提供 Windows 轻量版。集中跟踪多个 Agent 的任务、处理支持的审批操作，查看可用额度与 Token 用量。 |
| [DeepViewer](https://github.com/Duoasa/DeepViewer) | 基于 DeepSeek Harness、为设计师打造的 Agent 工作空间，原生集成 DSH-to-Figma，串联创意探索、可编辑 Figma 设计、素材处理与可运行原型。 |
| [DSH-to-Figma](https://github.com/Duoasa/DSH-to-Figma) | 让 DeepSeek Harness 用自然语言读取、创建和编辑 Figma 设计，涵盖组件、变量、编辑器支持的原生动效、截图与素材导出。本地模式不消耗官方 Figma MCP 调用额度。 |
| [Duoasa Design](https://github.com/Duoasa/Duoasa-Design) | 用 Codex、WebGL 动效和规则驱动工作流构建的个人设计作品集，探索从设计想法到可运行网站的完整过程。 |
| [interactive-component-integration](https://github.com/Duoasa/interactive-component-integration) | 面向 Codex 与 DSH 的交互组件集成 Skill，忠实集成 Canvas、WebGL、着色器与交互效果，保留源组件的渲染流程，并约束集成范围、进行视觉验证。 |
